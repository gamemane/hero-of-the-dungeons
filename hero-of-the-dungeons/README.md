# Hero of the Dungeons

Roguelike dungeon crawler in Python + pygame.

## Run
    pip install pygame
    python main.py

## Controls
- Arrows/WASD - move/attack; click a cell - walk there
- 1-9 - cast learned spells (targeted spells ask to click a target)
- O - Spells panel, T - Talents, I - Items, C - Craft, B - Shop
- F5 save / F9 load, R restart, Esc close panel, mouse wheel scrolls panels

## Modes
- normal / medium / hardcore (death erases saves) / fog (vision radius 4)
